    05 / FAQ

    Archive protocol.

    Does it work with private repositories?

    Private repositories are not supported yet.

    What is a universe number?

    A stable four digit ID derived from a commit hash.

    Why does the Sacred Timeline look different?

    It is always the repository's default branch.

    Is my code stored?

    No. GitVerse reads history metadata and does not keep your code.
